PROTOCOLTC—001
RESEARCH QUESTION

Does social ratification make discovered functions more useful?

Each world evolves a population of tiny expression trees to reproduce a sequence of deterministic nibble transformations. All arms receive the same target schedule and training examples for each paired seed. Each arm starts from the same population and uses a seeded local search stream.

Four comparison arms

  1. Closed grammar. Programs mutate and recombine within their own lineage; no shared artifacts enter the grammar.
  2. Snippet relay. High-ranking programs contribute raw expression fragments to a shared mutation pool.
  3. One-lineage opcodes. A fragment's exact 256-entry function table becomes a callable instruction after one lineage exposes it.
  4. Ratified opcode commons. Publication additionally requires single-founder program lineages that are distinct from one another, plus observations in two task families. Inactive operations expire after two epochs.

Task world

The machine has two 4-bit inputs and a small primitive set: bitwise XOR, AND, OR, modular addition and subtraction, rotate-left, rotate-right, and complement. Five acquisition target expressions reuse motifs in different contexts. Training examples are sampled from the 256 possible input pairs; acquisition accuracy is scored on the full table.

Frozen composition transfer

After acquisition, each arm freezes its learned vocabulary, discards its trained population, and starts each of eight public held-out compositions with the same fresh population and sampled examples. The arms receive the same population-by-generation search slots; publication and expiry are disabled. Exact accuracy is scored over all 256 pairs. This is few-shot adaptation to new target structures in the same DSL, not zero-shot transfer, a secret benchmark, or a different interpreter.

Outcomes and ablations

Search uses exact training accuracy plus a smaller per-bit agreement signal and an expression-size penalty. The primary outcome is paired mean exact accuracy on the eight frozen composition tasks; acquisition accuracy on familiar targets is reported separately. Other measures include exact-task rate, generations to an exact solution, effective and expanded program size, population diversity, opcode reuse, publication, and expiry.

Interpretation boundary

This is a finite symbolic toy world. Full truth-table enumeration is exact for its 4-bit machine. Results do not establish general program synthesis, open-ended evolution, biological memory, consciousness, or real-world code reliability. A learned opcode is a named function table, not a new mathematical function. A positive result is evidence only about this benchmark and its specified search process.

Reproducibility

The engine uses a local deterministic PRNG. The v2 JSON receipt records both task manifests, exact sampled pairs, initial-population digests, acquired vocabularies, per-task metrics, and opcode events. The phase-labeled CSV is for downstream analysis. Paired-seed bootstrap intervals describe only these simulated replications.
